DLove-style Trung Thu clone
===========================

Open index.html in a modern browser. The page is built from the supplied screen recording and URL reference.

Flow:
1) Press and hold the moon on the first scene.
2) Floating messages/photo layer appears.
3) Heart/photo scene follows automatically.
4) Tap the heart scene or the gift button to open the letter.
5) X closes the letter.
6) Speaker button toggles the extracted audio track from the supplied recording.

Assets were extracted from the supplied screen recording. Exact source-site HTML/CSS/JS was not available through the page reader, so the implementation recreates the observed visuals and interactions rather than claiming a source-identical copy.
